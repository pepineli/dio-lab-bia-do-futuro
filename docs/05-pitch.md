# Pitch (3 minutos)


## Roteiro 

### 1. O Problema (30 seg)

Os conteúdos de educação financeira disponíveis são genéricos e não consideram a realidade de cada pessoa. Quem tem renda variável, por exemplo, precisa de orientação diferente de quem tem salário fixo, mas raramente encontra exemplos práticos para sua situação.

### 2. A Solução (1 min)

O Lúcio roda localmente com Streamlit e Ollama, garantindo privacidade. Ele é alimentado por uma base de conhecimento mockada que simula uma cliente real (Mariana), permitindo demonstrar exemplos práticos sem acessar dados sensíveis. O sistema foi projetado para evitar alucinações e nunca dar conselhos financeiros inadequados.

### 3. Demonstração (1 min)

Na demonstração, vou mostrar três interações com o Lúcio:

- O usuário pergunta "Quanto devo guardar por mês para minha reserva de emergência?" – o Lúcio responde com base nos dados da Mariana (10-20% da renda variável).
- O usuário pede recomendação de ação – o Lúcio recusa educadamente e explica o conceito de ações.
- O usuário pergunta algo fora do escopo (previsão do tempo) – o Lúcio redireciona para finanças.

### 4. Diferencial e Impacto (30 seg)

O maior diferencial do Lúcio é o cuidado com o usuário. Ele foi desenhado para reduzir a ansiedade financeira, respeitando o ritmo de aprendizado de cada um. O impacto é formar uma geração mais consciente e preparada para lidar com dinheiro.
